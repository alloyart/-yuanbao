# Yuanbao Growth Center Redesign

Static case-study site for the Tencent Yuanbao Growth Center redesign.

- Static portfolio pages are rendered as full-width exported frames for exact visual fidelity.
- Two interaction demos are embedded directly after the cover and autoplay muted in a loop.
- Video delivery format: H.264 MP4 for broad browser support.
- Deployment target: GitHub Pages.
